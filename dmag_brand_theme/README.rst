================
DMAG Brand Theme
================

Áp dụng màu nhận diện DMAG cho giao diện quản trị Odoo: thanh menu màu navy
``#11346A``, nút chính và liên kết màu xanh ``#178BEC``. Không thay đổi dữ
liệu, gỡ module là trở về giao diện mặc định.

Logo công ty (màn hình đăng nhập, báo cáo) cấu hình tại *Thiết lập > Công ty*.
